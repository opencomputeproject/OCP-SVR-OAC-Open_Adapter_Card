        OAC CID Editor — Help
        
      

      

        
        
        
        
      

      


        
        

          
1
Choose a mode
Use the CID / Connector Profile toggle in the header to select what you're authoring. A CID describes a complete adapter. A Connector Profile defines a reusable, OCP-ratified pinout for a single connector position.

          
2
Fill in Metadata & Power
In CID mode, start with the Metadata section (schema version, spec revision, adapter description), then complete the Power section (input voltage, connector type, and all required OPL fields).

          
3
Configure Connectors
Use the left nav to jump to each connector (CONN0–CONN6). Mark a connector as Populated to unlock its signal sections. For each connector, either reference an OCP-ratified Connector Profile, or define High-Speed Lanes, Clocking, and Discrete Signals explicitly — not both.

          
4
Assign Pins
Expand the Visual Pin Map for each connector to assign physical pins to lane signals, clock signals, and discrete signals by clicking on pin cells. The map enforces position constraints automatically.

          
5
Validate & Export
Watch the validation badge in the JSON Preview panel for errors and warnings. When the badge shows ✓ Valid, use Export JSON to save your CID as a formatted or minified JSON file ready for firmware integration.

          
6
Import an existing CID
Use Import JSON to load an existing CID or Connector Profile file. The editor will auto-detect the document type, switch to the correct mode, and populate all fields. Switching to Manual mode gives you direct JSON editing with live syntax highlighting.
