OCP
OAC Adapter — CID Compliance Check Logic
Open Adapter Card · Connector Interface Definition · JSON Schema
The BMC evaluates each incoming adapter CID (oac_cid JSON) through a sequence of checks. A single FAIL blocks power-on. One or more WARNs (with no FAILs) results in degraded operation. All PASS yields full normal operation.
Outcomes: FAIL — power denied WARN — degraded PASS — compliant
BMC receives adapter CID (oac_cid JSON)
1
Schema Validation
metadata.schema_version
✕ FAIL schema_version missing or unrecognized by BMC firmware
✓ PASS schema_version recognized — proceed to further checks
2
Input Voltage
power.primary.input_voltage
✕ FAIL input_voltage field missing
✕ FAIL Declared input_voltage does not match slot-provided voltage
✓ PASS Declared voltage matches slot supply
3
Connector Type
power.primary.connector_type
✕ FAIL connector_type field missing
✕ FAIL Slot does not support declared variant (e.g., "125A" declared in a "100A" rated slot)
✓ PASS Connector type is compatible with slot
4
OPL-MAX Power Budget
power.primary.opl_max_w
✕ FAIL opl_max_w field missing
✕ FAIL Declared opl_max_w exceeds slot power capacity
✓ PASS OPL-MAX is within the slot's power budget
5
OPL-EMG Declared
power.primary.opl_emg_w
✕ FAIL opl_emg_w field missing
✕ FAIL Declared opl_emg_w > opl_max_w (emergency cannot exceed maximum)
✓ PASS OPL-EMG is declared and does not exceed OPL-MAX
6
Connector Impedance  per populated connector
connectors[].impedance_ohm
✕ FAIL No matching baseboard connector definition found
✕ FAIL Declared impedance_ohm does not match baseboard specification
⚠ WARN impedance_ohm undeclared — cannot verify impedance compatibility
✓ PASS Impedance matches baseboard definition for all populated connectors
7
Connector Profile Resolution  per connector with profile
connectors[].connector_profile
✕ FAIL OAC-PROF- identifier unrecognized by BMC firmware and no explicit override provided
✕ FAIL VENDOR- profile FRU File not found and no explicit section override present
✓ PASS Profile resolved successfully, or all sections explicitly overridden
8
High-Speed Lane Protocol / Role / Direction / Min Lanes  per connector with hs
high_speed_lanes.protocol · .link_role · .link_direction · .minimum_lanes
✕ FAIL No baseboard high-speed lane definition found for this connector
✕ FAIL Any mismatch in protocol, link_role, or link_direction
✕ FAIL Available baseboard lanes < declared minimum_lanes
✓ PASS Protocol, role, direction all match; available lanes ≥ minimum_lanes
9
Lane Pin Assignments  per connector
lanes[required=true]
✕ FAIL A required lane is missing from the adapter CID declaration
✕ FAIL Pin assignment for a required lane does not match baseboard definition
⚠ WARN Declared total_lanes is less than baseboard-supported lane count (reduced lane width)
✓ PASS All required lanes present and pin assignments match
10
Reference Clocking  per required clock
clocking[required=true]
✕ FAIL A required clock signal is missing from the adapter CID
✕ FAIL Clock type, frequency, pin assignment, or direction mismatch
✓ PASS All required clocks declared and match baseboard definition
11
Required Discrete Signals
discrete_signals[required=true]
✕ FAIL A required discrete signal is missing from the adapter CID
✕ FAIL Pin assignment for a required discrete signal does not match baseboard
✓ PASS All required discrete signals present with matching pin assignments
12
OAC Spec Revision
metadata.oac_spec_revision
⚠ WARN oac_spec_revision undeclared — revision compatibility cannot be confirmed
⚠ WARN Declared revision differs from baseboard target revision
✓ PASS Declared oac_spec_revision matches baseboard target revision
Compliance Verdict
✕ BLOCKED
Any FAIL result in checks 1–11
OAC_PWR_EN de-asserted — adapter power denied
⚠ DEGRADED
No FAILs — one or more WARNs
OAC_PWR_EN asserted — reduced capability, BMC logs warning
✓ NORMAL
All checks PASS — zero WARNs
OAC_PWR_EN asserted — full capability enabled
