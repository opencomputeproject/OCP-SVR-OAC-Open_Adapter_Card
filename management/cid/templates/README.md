# Templates

This folder contains the blank CID JSON template for authoring new OAC adapter Connector Interface Definition documents. Files are organized by specification revision.

| Version | Contents |
|---------|----------|
| [v0.9](v0.9/) | Template for OAC CID Specification v0.9 |

When authoring a new CID, always use the template that corresponds to the CID specification version your adapter targets.
